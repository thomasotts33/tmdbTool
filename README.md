# TMDB CLI App

A beginner Python command-line application that uses the TMDB API to fetch and display movie titles in the terminal. This project aligns with the roadmap.sh TMDB CLI project, which focuses on API consumption, JSON handling, and building a simple CLI tool. :contentReference[oaicite:0]{index=0}

## Project Links

- roadmap.sh project: https://roadmap.sh/projects/tmdb-cli
- GitHub profile: https://github.com/thomasotts33

## Features

This application lets the user choose from the following movie categories:

- Now Playing
- Popular
- Top Rated
- Upcoming

The script then sends a request to TMDB and prints the movie titles in a numbered list in the terminal. The roadmap.sh project specifies these same categories as core requirements for the CLI app. :contentReference[oaicite:1]{index=1}

## Tech Stack

- Python
- `requests`
- `python-dotenv`

## Requirements

Before running the app, make sure you have:

- Python 3.8 or newer
- `pip`
- A TMDB API key
